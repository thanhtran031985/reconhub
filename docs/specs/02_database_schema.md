# Spec 02 – Schema RECON_APP (SQLite mặc định, Oracle 19c+)

Nguồn sự thật: `app/db/metadata.py` (SQLAlchemy Core). Alembic sinh migration; mọi revision chạy được trên SQLite (batch mode) và Oracle.

## 0. Quy ước kiểu

| Kiểu trung lập | SQLAlchemy | SQLite | Oracle |
|---|---|---|---|
| ID | `BigInteger().with_variant(Integer, "sqlite")`, `Identity()` | `INTEGER PRIMARY KEY` | `NUMBER(19) GENERATED BY DEFAULT AS IDENTITY` |
| STR(n) | `String(n)` | `VARCHAR(n)` (độ dài validate ở Pydantic) | `VARCHAR2(n CHAR)` |
| TEXT | `Text` | `TEXT` | `CLOB` |
| JSON | `JsonText` | `TEXT CHECK (json_valid(col))` | `CLOB CHECK (col IS JSON)` |
| TS | `DateTime` (UTC naive) | `TEXT` ISO | `TIMESTAMP(3)` |
| DEC | `DecimalText` | `TEXT` (chuỗi Decimal, **không REAL**) | `NUMBER(38,4)` |
| INT | `Integer` | `INTEGER` | `NUMBER(10)` |
| FLAG | `String(1)` 'Y'/'N' | `TEXT` | `CHAR(1)` |

- Tên bảng/cột HOA, ≤ 30 ký tự; tên ràng buộc tường minh (naming convention).
- SQLite: file `data/recon_app.db`, `auto_vacuum=INCREMENTAL` khi tạo; mỗi kết nối bật WAL, `foreign_keys=ON`, `busy_timeout=30000`, `synchronous=NORMAL`. Yêu cầu SQLite ≥ 3.35.
- Vì DEC lưu TEXT trên SQLite, không tính tổng tiền bằng SQL trên RECON_APP; tổng đã tính sẵn ở RECON_RUN_SUMMARY. Sắp xếp theo chênh lệch dùng cột `ABS_DIFF_SORT` (REAL, chỉ để sắp xếp).

## 8. Dialect (`app/db/dialect.py`)

| Việc | SQLite | Oracle |
|---|---|---|
| Lấy job | `BEGIN IMMEDIATE` + `UPDATE … WHERE RUN_ID=(SELECT … LIMIT 1) RETURNING RUN_ID` | `SELECT … FOR UPDATE SKIP LOCKED` + `FETCH FIRST 1 ROWS ONLY` |
| Phân trang | `LIMIT/OFFSET` | `OFFSET … FETCH NEXT …` |
| Upsert | `INSERT … ON CONFLICT DO UPDATE` | `MERGE` |
| JSON, Decimal | TEXT ↔ dict/Decimal trong TypeDecorator | CLOB/NUMBER ↔ dict/Decimal |
| Thu hồi dung lượng | `PRAGMA incremental_vacuum` | không cần |
| Dung lượng | `dbstat` hoặc ước lượng qua BYTES_EST | `USER_SEGMENTS` |
| Sao lưu | `VACUUM INTO 'backup/recon_app_<ngày>.db'` | theo DBA |
