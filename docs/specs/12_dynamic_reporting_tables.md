# Spec 12a – Thiết kế bảng Dynamic Reporting

Các bảng có audit fields, UTC timestamps và ROW_VERSION khi sửa được.

| Bảng | Cột chính |
|---|---|
| RECON_REPORT | ID, CODE UQ, NAME, CATEGORY_CODE, OWNER, DESCRIPTION, DEFAULT_FAVORITE, IS_VISIBLE, IS_ACTIVE |
| RECON_REPORT_TEMPLATE | ID, REPORT_ID, CODE, NAME, DISPLAY_ORDER, ACTIVE_VERSION_ID; UQ(REPORT_ID,CODE) |
| RECON_RPT_TPL_VER | ID, TEMPLATE_ID, VERSION_NO, STATUS, DATA_SOURCE_ID, SOURCE_TYPE, SQL_TEXT, SOURCE_OWNER, SOURCE_OBJECT, TIMEOUT_SEC, PREVIEW_MAX_ROWS, EXPORT_MAX_ROWS, SQL_HASH, ACTIVATED_BY/AT |
| RECON_RPT_PARAM | ID, VERSION_ID, CODE, LABEL, DATA_TYPE, CONTROL_TYPE, REQUIRED, DEFAULT_TYPE/VALUE, DISPLAY_ROW, DISPLAY_ORDER, GRID_SPAN, FILTER_COLUMN, FILTER_OPERATOR, IS_VISIBLE |
| RECON_RPT_PARAM_LOV | PARAM_ID PK, LOV_TYPE, DATA_SOURCE_ID, SQL_TEXT, LOOKUP_TYPE, STATIC_JSON, CACHE_SECONDS, MAX_ROWS |
| RECON_RPT_COLUMN | ID, VERSION_ID, FIELD_NAME, LABEL, DATA_TYPE, DISPLAY_ORDER, WEB_VISIBLE, EXCEL_VISIBLE, FORMAT_MASK, ALIGNMENT, WIDTH, IS_TOTAL |
| RECON_REPORT_RUN | ID, REPORT_ID, TEMPLATE_ID, VERSION_ID, PARAMS_JSON, STATUS, ROW_COUNT, QUERY_MS, ERROR_CODE/MESSAGE, CREATED_BY/AT, FINISHED_AT |
| RECON_RPT_EXPORT | ID, RUN_ID, FORMAT, STATUS, FILE_PATH, FILE_SIZE, FILE_HASH, PART_COUNT, ROW_COUNT, CREATED_BY/AT, FINISHED_AT, ERROR_MESSAGE |
| RECON_RPT_FAVORITE | USER_ID, REPORT_ID, CREATED_AT; PK(USER_ID,REPORT_ID) |
| RECON_RPT_PRESET | ID, USER_ID, REPORT_ID, TEMPLATE_ID, NAME, PARAMS_JSON, IS_DEFAULT |
| RECON_RPT_LOV_CACHE | CACHE_KEY PK, PAYLOAD_JSON/CLOB, ROW_COUNT, EXPIRES_AT, CREATED_AT |

Ràng buộc:
- SOURCE_TYPE in CUSTOM_SQL, VIEW, TABLE.
- Version status in DRAFT, DRY_RUN_OK, ACTIVE, ARCHIVED; UQ(TEMPLATE_ID,VERSION_NO); chỉ một ACTIVE (service + transaction lock).
- GRID_SPAN 1..12, DISPLAY_ROW >=1; service kiểm tổng mỗi row <=12.
- LOV_TYPE in NONE, STATIC, SQL, LOOKUP; SQL yêu cầu aliases VALUE/LABEL; STATIC JSON values unique.
- SOURCE_OWNER/SOURCE_OBJECT bắt buộc với VIEW/TABLE; SQL_TEXT bắt buộc với CUSTOM_SQL.
- FORMAT in XLSX, CSV, ZIP; run/export owner-filter theo CREATED_BY.

Oracle metadata cache không cần bảng riêng ở phase đầu; cache memory theo Data Source + schema + object + revision. SQLite chứa metadata cấu hình; Oracle chỉ là nguồn đọc.
