  1. File mẫu: chỉ dùng để học cấu trúc file (sheet, header, dòng tổng), không quyết định khoảng thời gian.
    2. 
      
  2. Định nghĩa trường: đặt tên chung (trường logic) cho các cột Excel cần dùng.
    3. 
      
  3. Nguồn DB: câu SQL chi tiết với tham số :p_from / :p_to / :p_org, map cột DB về cùng trường logic.
    4. 
      
  4. Profile: chọn mức gộp và cách so sánh.
  5. Dry-run: người dùng nhập khoảng ngày giờ để chạy thử trước khi lưu.

sequenceDiagram
  actor U as Người dùng
  participant UI as ReconHub UI
  participant API as API
  participant W as Worker
  participant DB as Oracle (read-only)
  U->>UI: Upload file + nhập Từ/Đến ngày giờ, ORG
  UI->>API: Tạo run (file, template, p_from, p_to, p_org)
  API->>API: Validate tham số và header file
  API-->>UI: run_id (READY)
  W->>API: Lấy run READY
  W->>W: Đọc Excel, chuẩn hóa, lọc theo p_from/p_to
  W->>W: Kiểm tra control total
  W->>DB: SQL gộp với :p_from, :p_to, :p_org
  DB-->>W: Dữ liệu đã GROUP BY
  W->>W: Ghép theo khóa, so measure
  W->>API: Lưu kết quả + file export
  UI->>API: Poll trạng thái
  API-->>UI: DONE → mở màn hình kết quả
