# Screen14-Permission – Vai trò và phân quyền (`/roles`, menu `role`)

Prototype đã duyệt: `ReconHub_Permission_Preview.html` (bản riêng đã gửi). Agent đặt file đó vào thư mục này với tên `preview.html`.

Điều chỉnh theo spec 11 mục 7.1 khi làm thật:
- Bỏ bảng "Phạm vi dữ liệu và thao tác đặc biệt"; thay bằng ghi chú một dòng.
- Danh sách checkbox menu đọc từ RECON_MENU (tên/nhóm/thứ tự hiển thị); nhãn **Mới** cho menu IS_NEW, **Đang ẩn** cho menu bị ẩn.
- Giữ 3 tab: Vai trò, Quyền thực tế của người dùng, Mô phỏng phạm vi dữ liệu.
