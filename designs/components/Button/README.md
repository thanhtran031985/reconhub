# Button

Nút hành động.

## Props và quy tắc

| Prop | Kiểu |
|---|---|
| variant | primary, secondary, ghost, danger (viền), danger-fill (xác nhận xóa) |
| size | md 36px, sm 28px (trong bảng) |
| loading, disabled, disabledReason | |
| icon | lucide |

Mỗi vùng một nút primary. Chữ là động từ.

## Kiểu dáng
Lớp `rh-…` trong `../bundle.css`; xem `../Gallery/preview.html`.
