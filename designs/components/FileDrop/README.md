# FileDrop

Vùng kéo thả/chọn file.

## Props và quy tắc

accept .xlsx/.xls/.csv; tối đa 50MB; có file: tên, dung lượng, Đổi file; `role=button`, Enter/Space.

## Kiểu dáng
Lớp `rh-…` trong `../bundle.css`; xem `../Gallery/preview.html`.

## Chuyển sang Dash
Hàm trong `app/ui/components/` theo bảng "Ánh xạ sang Dash Mantine" ở `designs/README.md`. Không dùng hex/px.
